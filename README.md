# Praneeth Portfolio

## Run the website

1. Extract this ZIP.
2. Open Command Prompt inside the extracted `praneeth-portfolio` folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost address printed in Command Prompt.

## Included
- React + Vite
- Tailwind CSS
- Framer Motion animations
- Responsive futuristic dark design
- Resume PDF already placed in `public/documents/Praneeth_Resume.pdf`

The content is based on the resume supplied for this portfolio.
